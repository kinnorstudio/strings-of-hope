# Strings of Hope

A lever-harp learning companion for the Strings of Hope community — modes, music theory, a tuner, a note reader, and daily practice.

**Open the app:** https://kinnorstudio.github.io/strings-of-hope/

Licences and sources are listed in the app under **You → Credits**, with full notices in `fonts/OFL.txt` and `vendor/LICENSES.txt`.
